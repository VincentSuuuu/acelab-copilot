# acelab-copilot

Ace Lab Max 是给 Laura 使用的个人内容灵感工作台，用 1-6 张客片生成小红书灵感、标题和极简文案。

## 在线地址

https://vincentsuuuu.github.io/acelab-copilot/

## v2 功能

- 三步工作流：灵感脑暴、标题生成、极简文案。
- 支持 Gemini 和 OpenAI / ChatGPT 引擎。
- OpenAI 默认模型：`gpt-5.5`。
- 支持多图上传，浏览器端自动压缩图片。
- 支持合规词检测、风险高亮和 AI 自动净化。
- 支持文案版本记录和本机草稿库。

## API Key

Gemini API Key:

https://aistudio.google.com/api-keys

OpenAI API Key:

https://platform.openai.com/api-keys

Laura 在右上角的引擎配置中心输入 Key。这个工具按个人使用场景设计，OpenAI Key 会保存在当前浏览器 cookie `acelab_openai_api_key` 中；Gemini Key 保存在当前浏览器的本地存储/cookie 中。请不要在共享设备上保存 Key。
